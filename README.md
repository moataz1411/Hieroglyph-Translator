# Hieroglyph Translator

A simple web for converting English letters into Egyptian hieroglyphic symbols.

I created this project to explore our ancient Egyptian writing and understand how text conversion works using HTML, CSS, and JavaScript. It allows users to convert text into hieroglyphic symbols.
